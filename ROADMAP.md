# MCPVeil roadmap

Shipped in 0.2: explicit active-test authorization, filtered target environment,
secret-safe outputs, cancellation/deadlines, shared budgets, non-destructive SQL
controls, honest failed/partial reports and supported Node engines.

Shipped in 0.3: recursive schema planning, setup diagnostics, labeled synthetic
benchmark with request/latency measurements, portable CI and a real CLI demo.

Shipped in 0.4: credential-safe authenticated HTTP, optional access-policy probes,
modern/legacy protocol compatibility, expiring target-scoped baselines, hashed
tool drift snapshots, and a reusable GitHub Action with isolated adversarial fixtures.

Future research: verified out-of-band SSRF callbacks, larger independent labeled
corpora, server-specific remediation packs and optional policy distribution.
Claims must follow measured evidence. Fixture recall is not universal accuracy.
